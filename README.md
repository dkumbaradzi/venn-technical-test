# Setup

- Install node `v24.12.0`
- If you are using nodenv, it will be automatically be able to pick up the version from the .node-version file as long as it is installed. If using nvm, run `nvm use` 
- Run `npm install`

## Running the Application in development mode

- Run `npm run dev`
- The application will be available on `http://localhost:5173`

## Running the Application in production mode

- Run `npm run build`
- Run `npm run preview`
- The application will be available on `http://localhost:4173`
